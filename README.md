# 模块化病毒查杀工具

作者：军不见　电话：180******66

一个面向 Windows 的模块化桌面工具：主程序只负责装配界面与调度，功能以模块形式扩展。源码使用 Python 3.8+ 与 tkinter；发行版为 PyInstaller 打包的单文件 exe。

## 现有模块

| 模块 | 功能 | 口径 |
|---|---|---|
| U盘/本地磁盘文件查杀 | 扫描 / 查杀 / 免疫 / 回滚（含系统盘） | 隔离而非删除；可回滚；系统关键路径只报告不改动 |
| 主机诊断（只读） | Run/RunOnce、IFEO、AppInit_DLLs、Winlogon、服务 DLL；可导出全注释修复脚本 | 只读注册表查询；脚本须人工复核后自行执行 |
| 经典木马体检 | QQ 尾巴启动项、关联劫持、IFEO、IE 首页、hosts、共享；高危项备份后修复 | 检测只读；修复前备份，可回滚 |
| 现代威胁检测（只读） | WMI 订阅、计划任务、BHO、脚本关联、进程路径、勒索痕迹 | 只读采集，不终止进程 |
| 本地特征库 | 空库初始化、规则校验、按库扫描、规则包导入/回滚、误报登记 | 只报告，不隔离 |
| ClamAV 外部引擎 | 引擎检查、特征库更新、文件/目录扫描 | 调用外部 `clamscan.exe`，只报告 |
| AMSI 脚本评估（只读） | Win10+ 经 AMSI 接口评估脚本文件，无 provider 时优雅降级 | 只读评估，不处置 |
| 活动威胁处置 | 扫描 / 强杀确证恶意进程树 / 清理关联持久化点 | 只认「确证恶意」锚点；疑点零修改；系统进程硬白名单；进程终止不可回滚，逐进程写快照 |

## 运行

源码运行：

```powershell
python FolderVirusKiller.py
```

命令行回滚：

```powershell
python FolderVirusKiller.py --restore "<隔离目录>"
```

exe 运行：进入 `dist\`，双击 `文件夹病毒查杀工具.exe`。

插件目录随运行方式变化：

- 源码运行：项目根目录的 `plugins\`
- exe 运行：exe 同级的 `dist\plugins\`

新增功能只需增加模块并在 `core/registry.py` 注册，不需要修改主程序。

## 安全边界

- 默认不直接删除文件：U盘与本地磁盘查杀均采用隔离 + 可回滚。
- 本地磁盘（含系统盘）默认可查杀：下拉框列出可移动盘与固定盘；系统盘处置前弹二次确认，取消勾选「允许本地固定磁盘」则全部固定盘拒绝。
- 系统关键路径护栏：`Windows`、`Program Files`、`ProgramData`、`System Volume Information`、`$Recycle.Bin`、`Recovery`、`pagefile.sys` 等只进报告，**不隔离、不改隐藏属性，也不作为强杀确证锚点**；这是避免系统不可启动的底线，不是查杀覆盖缺口。
- 主机诊断与现代威胁检测均为只读，不写注册表、不终止进程。
- 本地特征库从空库起步，不伪造病毒库。
- ClamAV 为按需扫描，不是实时防护。
- 外部引擎命中需人工复核；命中不等于最终定性。
- 本工具定位「辅助诊断 / 第二意见按需扫描」，不是完整杀毒替代品：不常驻监控、无实时防护、无云端情报。
- 扫描跳过重解析点与超限文件；报告分别计「已扫描/跳过/无法读取/检测/未知」。
- 隔离记录 SHA-256 与原始路径/时间戳，回滚前显示摘要并逐项校验；这是准事务补偿，不是原子保证：进程若在搬移与落盘之间被强制终止，仍可能需要人工核对清单与磁盘，不承诺任何情况下的一致性。
- 中断/失败按磁盘真实状态幂等收敛为 `compensated / conflict / failed`：搬移前先登记 `pending` 落盘，以尽量缩小清单外孤儿的窗口；源与目标并存时保留两份、绝不覆盖；重复补偿结果一致。部分失败后清单状态统一，不残留 `pending`/`quarantined` 混淆回滚摘要。
- 回滚/补偿写回目标用 `O_CREAT|O_EXCL` 独占创建 + 复制 + fsync + SHA-256 校验后删源：把「目标不存在检查」与「创建」合成一次原子操作，若检查后目标被其他进程抢先创建则拒绝覆盖、保留两份副本并标记 `conflict`，避免 `exists()` 与搬移之间的竞态覆盖用户文件。
- 清单采用同目录临时文件 + 刷新 + 原子替换写入，避免写到一半留下半截 JSON；成功回滚的项标记 `restored` 并逐项原子落盘（每完成一项即写回），回滚摘要只统计 `quarantined`，重复回滚不会把已恢复项误报为失败。这降低清单损坏风险，但仍不等同于数据库事务。
- 规则包支持 SHA-256 完整性校验（非数字签名）；缺哈希的旧包仅警告。
- CI 构建产物附 SHA-256 清单；误报申诉流程见 `使用说明.md`。

完整判定口径、界面说明与操作步骤见 [`使用说明.md`](使用说明.md)。
