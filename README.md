# 模块化病毒查杀工具

作者：军不见　电话：180******66

一个面向 Windows 的模块化桌面工具：主程序只负责装配界面与调度，功能以模块形式扩展。源码使用 Python 3.8+ 与 tkinter；发行版为 PyInstaller 打包的单文件 exe。

## 现有模块

| 模块 | 功能 | 口径 |
|---|---|---|
| U盘文件查杀 | 扫描 / 查杀 / 免疫 / 回滚 | 隔离而非删除；可回滚 |
| 主机诊断（只读） | Run/RunOnce、IFEO、AppInit_DLLs、Winlogon、服务 DLL；可导出全注释修复脚本 | 只读注册表查询；脚本须人工复核后自行执行 |
| 经典木马体检 | QQ 尾巴启动项、关联劫持、IFEO、IE 首页、hosts、共享；高危项备份后修复 | 检测只读；修复前备份，可回滚 |
| 现代威胁检测（只读） | WMI 订阅、计划任务、BHO、脚本关联、进程路径、勒索痕迹 | 只读采集，不终止进程 |
| 本地特征库 | 空库初始化、规则校验、按库扫描、规则包导入/回滚、误报登记 | 只报告，不隔离 |
| ClamAV 外部引擎 | 引擎检查、特征库更新、文件/目录扫描 | 调用外部 `clamscan.exe`，只报告 |
| AMSI 脚本评估（只读） | Win10+ 经 AMSI 接口评估脚本文件，无 provider 时优雅降级 | 只读评估，不处置 |

## 运行

源码运行：

```powershell
python FolderVirusKiller.py
```

命令行回滚：

```powershell
python FolderVirusKiller.py --restore "<隔离目录>"
```

exe 运行：进入 `dist\`，双击 `文件夹病毒查杀工具.exe`。

插件目录随运行方式变化：

- 源码运行：项目根目录的 `plugins\`
- exe 运行：exe 同级的 `dist\plugins\`

新增功能只需增加模块并在 `core/registry.py` 注册，不需要修改主程序。

## 安全边界

- 默认不直接删除文件：U盘查杀采用隔离 + 可回滚。
- 主机诊断与现代威胁检测均为只读，不写注册表、不终止进程。
- 本地特征库从空库起步，不伪造病毒库。
- ClamAV 为按需扫描，不是实时防护。
- 外部引擎命中需人工复核；命中不等于最终定性。
- 本工具定位「辅助诊断 / 第二意见按需扫描」，不是完整杀毒替代品：不常驻监控、无实时防护、无云端情报。
- 扫描跳过重解析点与超限文件；报告分别计「已扫描/跳过/无法读取/检测/未知」。
- 隔离记录 SHA-256 与原始路径/时间戳，回滚前显示摘要并逐项校验；这是准事务补偿，不是原子保证。
- 规则包支持 SHA-256 完整性校验（非数字签名）；缺哈希的旧包仅警告。
- CI 构建产物附 SHA-256 清单；误报申诉流程见 `使用说明.md`。

完整判定口径、界面说明与操作步骤见 [`使用说明.md`](使用说明.md)。
